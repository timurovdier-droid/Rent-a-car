# Qween — Система управления автопарком

Веб-приложение для управления автопарком, водителями, платежами и арендодателями. Поддерживает четыре роли: Администратор, Диспетчер, Водитель и Арендодатель.

## 🏗 Архитектура

- **Frontend**: React + Vite (порт 5173)
- **Backend**: Node.js + Express (порт 3000)
- **Database**: PostgreSQL 14+

## 📋 Требования

- Node.js 18+
- PostgreSQL 14+
- npm или yarn
